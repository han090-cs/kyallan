🛠️ စစချင်း Project အိုင်ဒီယာ ၃ ခု (အဆင့်လိုက်)

အဆင့် ၁ (EDA): Exoplanet Archive CSV ကို ဒေါင်းပြီး "ရှာနည်း (discovery method) အလိုက် ဂြိုဟ် အရေအတွက် ဘယ်လို ပြောင်းလာသလဲ"၊ "habitable zone ဂြိုဟ်တွေရဲ့ အရွယ်အစား ဖြန့်ဖြူးမှု" ကို plot ဆွဲကြည့်ပါ။
အဆင့် ၂ (Time Series): NASA POWER API ကနေ မန္တလေး/မိုးကုတ် အတွက် နှစ် ၂၀ မိုးရေချိန် ဆွဲပြီး မုတ်သုံ pattern ကို analysis လုပ်၊ ရိုးရှင်းတဲ့ forecast model စမ်းကြည့်ပါ။
အဆင့် ၃ (ML): Kepler light curve ဒေတာကနေ transit ရှိတဲ့/မရှိတဲ့ ကြယ်တွေကို classification model တစ်ခု train ကြည့်ပါ — feature engineering အဖြစ် period, depth, duration တွေ သုံးနိုင်တယ်။
