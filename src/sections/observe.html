အပိုင်း ၁၅ · ကောင်းကင် ကြည့်ရန် လမ်းညွှန်

မြန်မာကနေ ကောင်းကင်ကို ကိုယ်တိုင် ကြည့်ကြည့်ရအောင်

တယ်လီစကုပ် မရှိလည်း စလို့ရတယ်။ မြန်မာက မြောက်လတ္တီကျု ၁၀°–၂၈° ကြားမှာ ရှိလို့ မြောက်ဘက် ကောင်းကင် (Orion, Ursa Major) ရော တောင်ဘက် ကောင်းကင် (Southern Cross, Milky Way အလယ်ပိုင်း) ပါ နှစ်မျိုးလုံး မြင်ရတဲ့ ကံကောင်းတဲ့ နေရာပါ။ မန္တလေး (~22°N) ကနေ ဆိုရင် အထူးသဖြင့် ဆောင်းရာသီ ညတွေ အကောင်းဆုံးပဲ။

🌌 ဘယ်အချိန် အကောင်းဆုံးလဲ

နိုဝင်ဘာ–ဖေဖော်ဝါရီ — မိုးကင်း၊ လေထု ခြောက်သွေ့၊ ကြည်လင်တဲ့ ဆောင်းညတွေ။ လ မရှိတဲ့ လကွယ် (new moon) အနီး ညတွေ က Milky Way နဲ့ မှိန်တဲ့ nebula တွေ အတွက် အကောင်းဆုံးပါ။ ည ၈–၁၀ နာရီက စပြီး မျက်စိကို အမှောင်နဲ့ ကျင့်သားရအောင် မိနစ် ၂၀ လောက် ဖုန်း မကြည့်ဘဲ ထားတာ (dark adaptation) က တကယ် ကွာခြားတယ်။

👀 မျက်စိနဲ့တင် မြင်ရတာတွေ

မြို့ အလင်းနဲ့ ဝေးရာမှာဆို — Milky Way အဖြူရောင် မြစ်လို အတန်း၊ Pleiades ကြယ်စု အစုလိုက်၊ Orion Nebula မှိန်မှိန် အစက်၊ Andromeda Galaxy (အလင်းနှစ် ၂.၅ သန်း — မျက်စိနဲ့ မြင်ရတဲ့ အဝေးဆုံး အရာဝတ္ထု)၊ ဂြိုဟ်တွေ ဖြစ်တဲ့ Venus, Jupiter, Saturn, Mars နဲ့ ဖြတ်သွားတဲ့ ISS ကိုပါ မြင်နိုင်တယ်။

🔭 ကိရိယာ — ဘယ်က စရမလဲ

အဆင့် ၁ — မျက်စိ + app: Stellarium (အခမဲ့၊ open source) ဖုန်းမှာ ထည့်ပြီး ကောင်းကင်ကို ချိန်ကြည့်ရင် ကြယ်/ဂြိုဟ် နာမည် တန်းသိရတယ်။ အဆင့် ၂ — binocular 10×50: လ အပေါက်တွေ၊ Jupiter ရဲ့ လ ၄ လုံး၊ ကြယ်စုတွေ အတွက် အကောင်းဆုံး စတင်ရာ။ အဆင့် ၃ — တယ်လီစကုပ်က နောက်မှ၊ အရင် ကောင်းကင် လမ်းကြောင်း (constellation တွေ) ကို သိအောင် လုပ်တာ ပို အရေးကြီးတယ်။

☄️ နှစ်စဉ် Meteor Shower ပြက္ခဒိန် — မြန်မာကနေ ကြည့်လို့ရတာတွေ

Meteor shower ဆိုတာ ကမ္ဘာက ကြယ်တံခွန် (comet) တွေ ထားခဲ့တဲ့ ဖုန် လမ်းကြောင်းထဲ ဖြတ်ဝင်ချိန် ဖြစ်ပေါ်တဲ့ "ကြယ်ကြွေ" တွေပါ။ ရက်စွဲတွေက နှစ်စဉ် အကြမ်းဖျင်း တူတူပဲ ဖြစ်ပြီး ZHR ဆိုတာ စံပြအခြေအနေ (အမှောင်ဆုံး ကောင်းကင်၊ radiant ခေါင်းပေါ် တည့်တည့်မှာ) မှာ တစ်နာရီ မြင်နိုင်တဲ့ အရေအတွက် ခန့်မှန်းပါ — လက်တွေ့မှာ ဒီထက် နည်းတတ်တယ်၊ လ အလင်း ရှိရင် ပို နည်းမယ်။

Showerအထွတ်အထိပ် ရက် (ခန့်)ZHR ခန့်မှန်းထူးခြားချက်
Quadrantidsဇန်နဝါရီ ၃–၄~60–80အထွတ်အထိပ် အချိန် တိုတယ် (နာရီ အနည်းငယ်) — ဆောင်းရာသီ ည သန်းခေါင်နောက်ပိုင်း ကြည့်ရန်။
Lyridsဧပြီ ၂၁–၂၂ (ခန့်)~18သမိုင်း အရှည်ဆုံး မှတ်တမ်းရှိတဲ့ shower (ဘီစီ ၆၈၇ ကတည်းက)။ တစ်ခါတလေ မီးလုံး (fireball) တွေ ပါတယ်။
Eta Aquariidsမေ ၅–၆~50Halley ကြယ်တံခွန်ရဲ့ အကြွင်းတွေ။ မိုးဦးရာသီ မိုးမရွာခင် မနက် စောစော ကြည့်ရန် အကောင်းဆုံး။
Perseidsဩဂုတ် ၁၂–၁၃~100လူကြိုက် အများဆုံး — ဒါပေမယ့် မြန်မာမှာ မိုးရာသီ အလယ်မို့ တိမ် ကင်းတဲ့ ညကို ကံ စမ်းရတယ်။
Orionidsအောက်တိုဘာ ၂၁–၂၂~20Halley ရဲ့ နောက်တစ်ကြိမ် လက်ရာ။ မိုးကုန်ခါနီး ရာသီမို့ Perseids ထက် မြန်မာမှာ အခွင့်အလမ်း ပိုကောင်းတယ်။
Leonidsနိုဝင်ဘာ ၁၆–၁၈ (ခန့်)~15၃၃ နှစ်တစ်ခါ "meteor storm" ဖြစ်တတ်တဲ့ shower — ပုံမှန် နှစ်တွေမှာ သင့်တင့်ရုံပဲ။
Geminidsဒီဇင်ဘာ ၁၃–၁၄~120–150တစ်နှစ်တာ အကောင်းဆုံး — ဆောင်းရာသီ အကြည်လင်ဆုံး ညနဲ့ တိုက်ပြီး မြန်မာအတွက် အခွင့်အလမ်း အကောင်းဆုံးပဲ။ အခြား shower တွေနဲ့ မတူ comet မဟုတ် ဥက္ကာခဲ 3200 Phaethon ကနေ လာတာ။

📌 ရက်စွဲ အတိအကျ သိချင်ရင် — အပေါ်က ဇယားက နှစ်စဉ် ပုံမှန် ရက်တွေ ဖြစ်ပြီး၊ အထွတ်အထိပ် ညက နှစ်အလိုက် တစ်ရက်လောက် ကွာနိုင်ပါတယ်။ ၂၀၂၆–၂၇ အတွက် လ အလင်း အခြေအနေ အပါအဝင် ရက်စွဲ အတိအကျ version ကို အောက်က အာကာသ ပြက္ခဒိန် ၂၀၂၆–၂၇ အပိုင်းမှာ သီးသန့် စုထားတယ်။

💻 ဖတ်ပြီး လက်တွေ့ လုပ်ကြည့်ရန် — ကိုယ်ပိုင် Space Project ၃ ခု

ဒီ site ထဲက Datasets နဲ့ API အပိုင်းတွေနဲ့ တိုက်ရိုက် ဆက်နွယ်တဲ့ စတင်ရာ project တွေ — data science ကျွမ်းကျင်မှုနဲ့ အာကာသ ဝါသနာကို တစ်ပြိုင်နက် လေ့ကျင့်နိုင်တယ်။

Project ၁ · ISS Tracker ကိုယ်တိုင် ဆောက်ရန်

အပေါ် Live အပိုင်းက ISS widget ရဲ့ နောက်ကွယ်က API (Where the ISS at?) ကို Python requests နဲ့ မိမိလိုအပ်ချက်အရ တစ်မိနစ်တစ်ကြိမ်ခန့်သာ ခေါ်ပြီး lat/lon မှတ်တမ်းကို CSV မှာ စု၊ matplotlib နဲ့ ကမ္ဘာ မြေပုံပေါ် လမ်းကြောင်း ဆွဲကြည့်ပါ။ API ခေါ်ခြင်း၊ time-series data နဲ့ plot ဆွဲခြင်း သုံးမျိုးလုံး တစ်ခါတည်း လေ့ကျင့်ပြီးသား ဖြစ်မယ်။

Project ၂ · Exoplanet Data စူးစမ်းရန်

NASA Exoplanet Archive ကနေ ဒေတာ download လုပ်ပြီး pandas နဲ့ စစ်ကြည့်ပါ — ဂြိုဟ်ရဲ့ အရွယ်/အပူချိန်နဲ့ ကြယ်ကနေ အကွာအဝေးကို scatter plot ဆွဲပြီး "habitable zone" ထဲ ကျတဲ့ ဂြိုဟ် ဘယ်နှစ် လုံး ရှိလဲ ရေတွက်ကြည့်တာ စတင်ရာ အကောင်းဆုံး EDA လေ့ကျင့်ခန်းပါ။ Kaggle မှာလည်း Kepler dataset အသင့် ရှိတယ်။

Project ၃ · APOD Archive ခွဲခြမ်းစိတ်ဖြာရန်

NASA APOD API နဲ့ နှစ်အလိုက် ဓာတ်ပုံ metadata (ခေါင်းစဉ်၊ ရှင်းလင်းချက်) တွေ စုပြီး စာသား ခွဲခြမ်းမှု လုပ်ကြည့်ပါ — ဘယ် နှစ်တွေမှာ ဘယ် အကြောင်းအရာ (nebula, galaxy, planet) အများဆုံး ပါလဲ၊ စကားလုံး အသုံးနှုန်း ပြောင်းလဲမှု ရှိလား ဆိုတာ word frequency နဲ့ trend plot ဆွဲလို့ ရတယ်။ နောက်တစ်ဆင့် image classification အထိ တိုးချဲ့လို့ရတဲ့ အခြေခံပါ။
