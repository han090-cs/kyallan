အချိန်နဲ့တပြေးညီ ဒေတာတွေ — API ကနေ တိုက်ရိုက်

ဒီအပိုင်းက public API တွေကရတဲ့ နောက်ဆုံး အာကာသဒေတာကို ပြပါတယ် ( = live data)။ NASA APOD၊ ဥက္ကာခဲ၊ သတင်း၊ arXiv၊ အာကာသထဲက လူနဲ့ လွှတ်တင်မှု အချိန်ဇယားအချို့ကို GitHub Actions ကနေ snapshot အဖြစ် update လုပ်ပြီး၊ ISS တည်နေရာနဲ့ NASA image search တို့ကို browser က တိုက်ရိုက်ခေါ်ပါတယ်။ အင်တာနက်/API ခဏတာ မရရင် widget တစ်ခုချင်းစီမှာ ပြန်ကြိုးစားနိုင်တဲ့ အသိပေးစာ ပြပါမယ်။

ISS အခု ဘယ်မှာလဲwheretheiss.at API

တစ်မိနစ်တစ်ကြိမ် အလိုအလျောက် ပြန် update လုပ်ပါတယ်။ မြင်ကွင်း (visibility) က "daylight" ဆိုရင် ISS အပေါ်မှာ နေရောင် ကျနေပြီး "eclipsed" ဆိုရင် ကမ္ဘာ့ အရိပ်ထဲမှာ ရှိနေတာပါ။

အခု အာကာသထဲမှာ လူ ဘယ်နှစ်ယောက် ရှိလဲPeople-in-Space HTTPS feed

NASA ရဲ့ Near Earth Object စောင့်ကြည့် စနစ်က ခြေရာခံနေတဲ့ အရာဝတ္ထုတွေပါ။ "အနီးဆုံး" ဆိုတာတောင် ပုံမှန်အားဖြင့် လ နဲ့ ကမ္ဘာ့ အကွာအဝေးရဲ့ အဆ များစွာ ဝေးပါသေးတယ် — စိုးရိမ်စရာ မဟုတ်ပါ။

ကမ္ဘာ တစ်လုံးလုံးရဲ့ နောက်ဆုံး ဓာတ်ပုံ (EPIC)NASA EPIC · DSCOVR
